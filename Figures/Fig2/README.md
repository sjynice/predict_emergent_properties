MD_transpt3.ipynb is used to train model predicting fate diversification or diversity realization, while NS_transpt3.ipynb for fate multiplicity, SS_transpt3.ipynb for transition species and Fl_transpt3.ipynb for persistent fluctuation.

The four "Loadmodelpt" are used to evaluate the prediction effect of the five surrogate models.

Database are generated using NumStable15.py in GenerateDatabase, and splited as train and test set using generate_split_index.ipynb.
